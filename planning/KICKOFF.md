# Kickoff: ό,τι ειπώθηκε και ό,τι δείχνουν οι διαφάνειες

Πηγές: η σελίδα https://hackathon.polymath42.com/deck/kickoff (14 Νοε), οι φωτογραφίες διαφανειών στο #notes της
ομάδας, το #announcements του Discord του hackathon. Ενημερώνεται όταν βγαίνει κάτι νέο.

## Τα σημαντικά με μια ματιά

- **Έπαθλα (επιβεβαιωμένα): 5.000 / 2.500 / 1.000 €**, χορηγία της **Quintessential**. Άρα η Quintessential είναι ο
  βασικός χορηγός και πολύ πιθανόν βαραίνει στην κρίση.
- **Παρουσίαση 3 λεπτών**, ίδια μορφή στον ημιτελικό (8 ομάδες, Κυρ ~19:00) και στον τελικό (4 ομάδες, Δευ 18:00).
- **Υποβολή Κυρ 18:00:** repo, βίντεο demo, στοιχεία project. Το πού υποβάλλουμε ανακοινώνεται αργότερα.
- **Open Track: επιπλέον πόντοι για hardware.**

## Οδηγίες της Quintessential για το πώς κερδίζεις

**Εστίαση:** «One user. One job, end to end. One wow moment.»

**Πρόγραμμα («Spend the weekend like this», 29 ώρες):**

| Πότε | Τι |
|---|---|
| Σάβ 13:00 | **Αποφασίζετε**: ομάδα, track, ο άνθρωπος για τον οποίο είναι. Οι άλλες ιδέες πεθαίνουν πριν το μεσημεριανό |
| Σάβ → 20:00 | **Άσχημο end-to-end**: από την είσοδο ως το αποτέλεσμα, να δουλεύει ως το δείπνο, όσο άσχημα κι αν είναι |
| Νύχτα | **Κάντε αληθινό το wow.** Μετά κοιμηθείτε· οι κουρασμένες ομάδες βγάζουν bugs |
| Κυρ πρωί | **Γυάλισμα της διαδρομής**: μόνο ό,τι αγγίζει το demo. Γράψτε το βίντεο νωρίς |
| Κυρ 18:00 | **Code freeze**: repo, βίντεο, στοιχεία. Υποβληθέντα, όχι «σχεδόν» |
| Κυρ 19:00 – Δευ 18:00 | **Pitch**: 8 ημιφιναλίστ, μετά 4 φιναλίστ στη σκηνή του ΚΠΙΣΝ |

**«Things that save teams»:**

- **Demo first.** Γράψτε το σενάριο των 3 λεπτών πριν τον κώδικα. Χτίστε μόνο ό,τι χρειάζεται το σενάριο.
- **Use real data.** Αληθινό inbox, αληθινό PDF, αληθινή φωτογραφία. Το lorem ipsum κρύβει κάθε ενδιαφέρον πρόβλημα.
- **Let the agents build it.** Coding agents για τον σκελετό· το μυαλό σας για την ιδέα.
- **Show the work.** Δείξτε βήματα, κλήσεις εργαλείων, πηγές. Το να βλέπεις έναν agent να κάνει τη δουλειά είναι η μισή μαγεία.
- **Have a plan B.** Το Wi-Fi πέφτει, τα API βάζουν όρια. Κρατήστε μια καλή εκτέλεση. Το βίντεο είναι η ασφάλειά σας.
- **Ask us.** Κολλήσατε 20 λεπτά; Βρείτε τους mentors.

**Pitch: «Three minutes, three beats»:**

| Χρόνος | Τι |
|---|---|
| 0:00 | **Ο άνθρωπος.** Ποιος έχει αυτή τη δουλειά και γιατί πονάει. Μία πρόταση, όχι μέγεθος αγοράς |
| 0:20 | **Το ζωντανό demo.** Κατευθείαν στη στιγμή wow. Αφήστε τον agent να τρέξει. Σταματήστε να μιλάτε όσο δουλεύει |
| 2:30 | **Τι ακολουθεί.** Τι θα χτίζατε με μία εβδομάδα ακόμη |

**«Six things that are a weekend now»** (τι θεωρούν εφικτό σε ένα διήμερο):

- **Agents that use tools:** καλούν API, τρέχουν κώδικα, χειρίζονται browser και εφαρμογές για ώρες.
- **Eyes and ears:** φωτογραφίες, screenshots, PDF, βίντεο, ζωντανός ήχος. Ό,τι δείχνει μια κάμερα είναι είσοδος.
- **Real-time voice:** συνομιλίες με διακοπές, τόνο και σχεδόν καθόλου καθυστέρηση.
- **Huge context:** ολόκληρο codebase, φάκελος συμβάσεων ή ένας χρόνος tickets σε ένα prompt.
- **Software on demand:** εφαρμογές από μία πρόταση ή ένα σκίτσο, UI που φτιάχνεται για κάθε χρήστη.
- **Connectors everywhere:** MCP: mail, ημερολόγια, έγγραφα, βάσεις, έτοιμα.

**Παραδείγματα ιδεών, «Direction 3: Content and digital art – Agents in the studio»** (είδαμε μόνο αυτή από τις 4 κατευθύνσεις):

- Script to storyboard: σελίδα σεναρίου μέσα, σταθεροί χαρακτήρες, πλάνα και πρόχειρο animatic έξω.
- The game that builds itself: επίπεδα, κανόνες και γραφικά από το πώς έπαιξες τον προηγούμενο γύρο.
- Campaign in a box: ένα brief, κάθε μορφή και κανάλι, ελεγμένα με το brand guide από agent που λέει «όχι».
- Visuals that listen: ζωντανά γραφικά που ακολουθούν τη μουσική, την αίθουσα ή τη φωνή του ομιλητή.

Οι άλλες τρεις κατευθύνσεις υπήρχαν στη διαφάνεια «Ideas 1–4 of 4» αλλά δεν φωτογραφήθηκαν. Αν κάποιος τις θυμάται, να
τις προσθέσει εδώ.

## Κανόνες

1. Ομάδες 1–5.
2. Χτίζεται εδώ. Ιδέες, εργαλεία και boilerplate επιτρέπονται· project ουσιαστικά έτοιμο από πριν μπορεί να αποκλειστεί.
3. Open source, δημόσια API και εργαλεία χορηγών επιτρέπονται, με σεβασμό στις άδειες και αναφορά σε ό,τι δεν χτίσαμε.
4. Το project είναι δικό μας. Οι διοργανωτές μπορούν να δείχνουν project, demo, βίντεο και ονόματα.
5. Χωρίς αλκοόλ, χωρίς παρενόχληση.
6. Κάμερες στον χώρο· όποιος δεν θέλει να φαίνεται, το λέει στους διοργανωτές.

## Ποιοι είναι οι κριτές; (για το to-do «research Quintessential»)

**Quintessential:** αθηναϊκό studio ψηφιακών προϊόντων, από το 2018, 25+ άτομα. Υπηρεσίες: ανάπτυξη προϊόντων,
**Aletheia AI** (στρατηγική AI, LLM, agentic automation, workshops), επέκταση ομάδων. Πελάτες: Relief Time, Up Hellas
(FlexOne), Pharmacy295, Avante Security, PPC Blue/Carge, Waiz (Εθνική Τράπεζα), HD Corner (Karabinis Medical), Viz,
Vespr, Castview. Αγορές: Ελλάδα, Βόρεια Αμερική, Ηνωμένο Βασίλειο, ΗΑΕ, Ισπανία. Πηγή: https://www.quintessential.gr

Για τα «Ostria» και «Conduit» δεν βρέθηκε τίποτα στο site τους ή σε αναζήτηση. Αν τα ανέφερε κάποιος στο kickoff, πείτε
από πού, να το ψάξουμε στοχευμένα.

**Τι σημαίνει για εμάς [εκτίμηση]:** κρίνουν άνθρωποι που φτιάχνουν προϊόντα για πελάτες κάθε μέρα. Θα προσέξουν αν η
λύση αφορά πραγματικό πελάτη με πραγματική δουλειά, αν το UI και η εμπειρία είναι προσεγμένα, και αν ο agent ενεργεί
αντί να απαντά.
