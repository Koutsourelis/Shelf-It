# Υλικό αποφάσεων

Ό,τι χρειάζεται συζήτηση πριν και κατά τη διάρκεια του hackathon, σε ένα σημείο. Γράφτηκε πριν το event
(13 Νοε 2026) και περιέχει μόνο ιδέες, έρευνα και σχέδια, όχι κώδικα του project.

| Αρχείο | Τι έχει | Πότε το ανοίγεις |
|---|---|---|
| [IDEAS.md](IDEAS.md) | Οι πέντε ιδέες, οι συνδυασμοί τους, σύγκριση | Σάββατο 13:00, μόλις ακουστούν τα tracks |
| [SITE_MAP.md](SITE_MAP.md) | Χάρτης του επίσημου site: tracks, πρόγραμμα, όροι, όροι Wonderful, credits, τι λείπει | Πρώτο. Έχει τα πιο πρόσφατα επίσημα στοιχεία |
| [RESEARCH.md](RESEARCH.md) | Κανόνες και πρόγραμμα του hackathon, τι κερδίζει, τι υπάρχει ήδη στην αγορά για κάθε ιδέα | Πριν διαλέξουμε ιδέα· όταν ρωτήσει κριτής «σε τι διαφέρετε» |
| [MENTORS_JUDGES.md](MENTORS_JUDGES.md) | Ποιοι είναι πιθανοί mentors και κριτές, πώς κρίνουν, τι σημαίνει για τη λύση, πλάνο mentoring | Πριν το kickoff· πριν το pitch |
| [DATA.md](DATA.md) | Τι αληθινά δεδομένα υπάρχουν για κάθε ιδέα και πώς στήνεται το demo | Πριν διαλέξουμε ιδέα· όταν στήνουμε το demo |
| [BUILD_PLAN.md](BUILD_PLAN.md) | Πώς χτίζεται: αρχιτεκτονική, ρόλοι, χρονοδιάγραμμα, βήματα ανά ιδέα | Σάββατο 14:00, μόλις κλειδώσει η ιδέα |
| [DECISIONS.md](DECISIONS.md) | Ανοιχτά ερωτήματα και ημερολόγιο αποφάσεων | Συνεχώς· κάθε απόφαση γράφεται εδώ με μία γραμμή |

Σχετικά: [../pitch/](../pitch/) για διαφάνειες, σενάριο demo και ερωτήσεις κριτών.

## Κανόνες χρήσης

- Κάθε απόφαση της ομάδας γράφεται στο `DECISIONS.md` τη στιγμή που παίρνεται, με ώρα και λόγο.
- Όπου γράφει **[Ε]** το στοιχείο είναι από επίσημη πηγή, **[Τ]** από τρίτη πηγή που δεν επαληθεύτηκε,
  **[Σ]** δική μας εκτίμηση. Πριν στηριχτεί απόφαση σε [Τ] ή [Σ], το ελέγχουμε.
- Κλειδιά, κωδικοί και προσωπικά στοιχεία δεν γράφονται ποτέ εδώ.
- Πριν την υποβολή αποφασίζουμε αν ο φάκελος μένει στο repo (δες `DECISIONS.md`, ερώτημα 9).
