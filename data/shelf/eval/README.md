# Eval set για το μοντέλο όρασης

Φωτογραφίες του **δικού μας** ραφιού με γνωστή αλήθεια. Με αυτές μετράμε κάθε αλλαγή στο prompt ή στο μοντέλο:

```bash
python scripts/eval_vision.py --runs 3
```

## Πώς προσθέτεις περίπτωση

1. Φωτογραφία από την κάμερα του demo, στη θέση του demo: `shelf_01.jpg`.
2. Δίπλα της `shelf_01.truth.json` με ό,τι **πραγματικά** υπάρχει:

```json
{
  "items": [
    {"sku": "C01", "shelf": 1, "facings": 2},
    {"sku": "C02", "shelf": 1, "facings": 3}
  ],
  "occluded": false
}
```

Αν η φωτογραφία βρίσκεται αλλού, βάλε `"photo": "data/shelf/photos/x.png"` αντί να την αντιγράψεις.

## Τι χρειαζόμαστε (10–15 περιπτώσεις)

| Περίπτωση | Πόσες |
|---|---|
| Σωστό ράφι | 2 |
| 1 προϊόν λείπει εντελώς | 2 |
| Λιγότερες προσόψεις | 2 |
| 2 προϊόντα ανταλλαγμένα (λάθος ράφι) | 2 |
| Ξένο προϊόν στο ράφι | 1 |
| Χέρι ή άνθρωπος μπροστά (`"occluded": true`) | 1 |
| Άλλο φως / λίγο άλλη γωνία | 2 |

Τα `sample_*` είναι οι δύο ζωγραφιστές φωτογραφίες του σκελετού, μόνο για να τρέχει το script. Με το mock βγάζουν
πάντα 100%, γιατί το mock διαβάζει ακριβώς το `.reading.json` τους.
