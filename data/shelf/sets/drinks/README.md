# Σετ «drinks»: ράφι ποτών με ελληνικά προϊόντα

Τρίτο σετ δεδομένων: ένα ράφι supermarket με μπύρες και αναψυκτικά, 37 αληθινούς ελληνικούς κωδικούς σε 5 ράφια.

**Οι φωτογραφίες δεν είναι αληθινές λήψεις.** Είναι σύνθεση από φωτογραφίες προϊόντων του sklavenitis.gr (15 Νοε
2026): κάθε συσκευασία κόπηκε από το λευκό φόντο και τοποθετήθηκε σε ράφι που σχεδιάζει κώδικας, στο πραγματικό της
μέγεθος. Δεν χρησιμοποιήθηκε μοντέλο εικόνας, οπότε οι συσκευασίες και τα γράμματα είναι ακριβώς τα αληθινά και η
«αλήθεια» κάθε φωτογραφίας είναι γνωστή με ακρίβεια (τη γράφει ο ίδιος κώδικας). Όπου δείχνουμε τις φωτογραφίες
(demo, παρουσίαση, trailer) λέμε ότι είναι συνθετικές. Οι συσκευασίες και τα σήματα ανήκουν στις εταιρείες τους·
πριν γίνει δημόσιο το repo, να αποφασίσει η ομάδα αν μένουν.

```
data/shelf/sets/drinks/
├── catalog.csv       37 κωδικοί (D01–D47): τιμές του sklavenitis.gr, κόστη φανταστικά (68% της τιμής)
├── planogram.csv     5 ράφια: φιάλες μπύρας · κουτιά 500ml · κουτιά 330ml · χωρίς αλκοόλ και αναψυκτικά · 1,5lt
├── backroom.csv      απόθεμα αποθήκης (D12 Mythos 500 και D43 Λουξ cola έχουν 0, για να φανεί η παραγγελία)
├── photos/           18 φωτογραφίες + sample_before/sample_after για το ψεύτικο μοντέλο
│                     δίπλα σε κάθε μία: .reading.json και .assessment.json (τι «βλέπει» το mock)
├── eval/             18 × .truth.json: κωδικός, ράφι, προσόψεις, τι λείπει
└── generator/        τα scripts που τις έφτιαξαν
```

## Οι φωτογραφίες

Τρεις εκδοχές του ίδιου ραφιού, έξι καταστάσεις η καθεμία (18 συνολικά, 2400×1800):

| Πρόθεμα | Πώς μοιάζει |
|---|---|
| `drinks_` | 3D: ράφι σε προοπτική, βάθος, καπάκια στα κουτάκια, σειρές πίσω, σκιές, γειτονικά ράφια, λήψη κινητού |
| `drinks_real_` | Επίπεδο ράφι με διάδρομο, φως καταστήματος και λήψη κινητού |
| `drinks_flat_` | Καθαρό σχέδιο από μπροστά, χωρίς εφέ κάμερας |

| Κατάσταση | Τι έχει |
|---|---|
| `full` | Γεμάτο, σύμφωνο με το planogram |
| `half` | Μισογεμάτο: λίγο βάθος, μερικές προσόψεις λιγότερες |
| `empty` | Σχεδόν άδειο: 12 κωδικοί λείπουν |
| `gaps` | Γεμάτο, εκτός από τρία κενά: D12, D22, D43 (το `sample_before` είναι αυτό, σε 3D) |
| `misplaced` | Heineken 330 στη θέση του Άμστελ 330, Λουξ λεμονάδα στη θέση του ΕΨΑ |
| `angle` | Μισογεμάτο, θερμότερο φως, λήψη από τα αριστερά |

Στα πλαϊνά ράφια φαίνονται προϊόντα που **δεν** είναι στον κατάλογο (Λουξ 330, Coca-Cola σε άλλες συσκευασίες).
Δεν μετράνε στην «αλήθεια»· είναι εκεί για να δούμε αν το μοντέλο κοιτάζει μόνο το ράφι στη μέση.

## Πώς τρέχει

```powershell
$env:SHELF_SET="drinks"
python scripts/make_demo_data.py
python scripts/eval_vision.py --runs 3      # με πραγματικό μοντέλο στο .env
python -m agentkit.server
```

Με `LLM_PROVIDER=mock`: `eval_vision.py` 100% (το mock διαβάζει τα `.reading.json`), `check_setup.py` «Όλα εντάξει».

## Ξαναφτιάξιμο

Στον φάκελο `generator/`, με τη σειρά: `scrape.py` (αναζήτηση στο sklavenitis.gr), `dl.py` (λήψη εικόνων προϊόντων
σε έναν φάκελο `raw/`), `make_shelf.py raw out`, `make_real.py raw out_real`, `make_3d.py raw out_3d`, και
`assemble.py <φάκελος> data/shelf/sets/drinks`. Οι εικόνες των προϊόντων δεν ανεβαίνουν στο repo.
