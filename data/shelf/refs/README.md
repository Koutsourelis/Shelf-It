# Φωτογραφίες αναφοράς

Το σωστά γεμάτο ράφι, με την **ίδια κάμερα, θέση και φως** με το demo. Στέλνεται στο μοντέλο μαζί με κάθε frame
(«αυτό είναι το σωστό, περίγραψε το τωρινό»), όταν το `.env` έχει:

```
VISION_REFERENCE=data/shelf/refs/shelf_ok.jpg
```

Αν η κάμερα μετακινηθεί, τραβάμε ξανά τη φωτογραφία. Το eval (`scripts/eval_vision.py`) δείχνει αν η αναφορά
βοηθάει: τρέξ' το με και χωρίς.
