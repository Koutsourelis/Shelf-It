## What existed before (declared boilerplate)

The commits up to the `boilerplate` tag are a generic agent skeleton prepared before the event (in a private repo,
imported here on 14 November so the team starts from a clean history), as the rules allow for
tooling and boilerplate. It contains no project-specific logic: an agent loop, model providers,
general tools (files, SQL, web, browser, email, PDF, extract/compute with audit trail), a console
that shows the agent's steps, run recording/replay, synthetic sample data and an empty pitch template
(`pitch/`: slide layout and demo checklist with placeholders, no project content). The `planning/` folder holds
the ideas and research notes written before the event. Details: [SKELETON.md](SKELETON.md).

`git log` shows the split: the commits up to the `boilerplate` tag, then the hackathon work.
