# Ερωτήσεις κριτών: προετοιμασία

Για κάθε ερώτηση: μία πρόταση απάντηση, ένα στοιχείο, τέλος. Απαντά ένας· οι άλλοι δεν συμπληρώνουν.
Τα `[...]` συμπληρώνονται με τα δικά μας στοιχεία. Αν δεν ξέρουμε κάτι, το λέμε και λέμε πώς θα το μάθουμε.

| Ερώτηση | Σκελετός απάντησης |
|---|---|
| Γιατί όχι απλώς ChatGPT ή Claude; | Αυτά απαντούν όταν τα ρωτήσεις. Το δικό μας ξεκινά μόνο του, έχει πρόσβαση στα [συστήματα/δεδομένα] και τελειώνει τη δουλειά με έγκριση. Δείχνουμε τη στιγμή που ξεκίνησε χωρίς εντολή. |
| Τι γίνεται όταν το μοντέλο κάνει λάθος; | Το μοντέλο δεν υπολογίζει: διαβάζει και αποφασίζει βήματα. Οι αριθμοί βγαίνουν από κώδικα και κάθε ένας έχει ίχνος ελέγχου. Καμία ενέργεια προς τα έξω δεν γίνεται χωρίς έγκριση. |
| Τι από αυτά χτίσατε εδώ; | [Λίστα διαφάνειας 6]. Ο γενικός σκελετός (βρόχος agent, κονσόλα, γενικά εργαλεία) ήταν έτοιμος από πριν και δηλώνεται στο README· το ιστορικό του git δείχνει τον διαχωρισμό. |
| Τα δεδομένα είναι πραγματικά; | Συνθετικά, φτιαγμένα να μοιάζουν με [κλάδος]. Με πραγματικά δεδομένα αλλάζει μόνο [η σύνδεση/ο πίνακας]. |
| Πόσο κοστίζει να τρέχει; | [Χ] λεπτά του ευρώ ανά εκτέλεση με [μοντέλο], [Υ] εκτελέσεις τον μήνα ανά πελάτη, άρα [Ζ] € τον μήνα. Οι προληπτικοί έλεγχοι είναι απλός κώδικας και δεν καλούν μοντέλο. |
| Ποιος θα πλήρωνε και πόσο; | [Ρόλος σε τύπο επιχείρησης]. Γλιτώνει [ώρες/ευρώ] τον μήνα, άρα [τιμή] τον μήνα είναι εύκολη απόφαση. |
| Ασφάλεια και προσωπικά δεδομένα; | Ο agent βλέπει μόνο τα εργαλεία που του δίνουμε, γράφει μόνο στον δικό του φάκελο, και κάθε εξωτερική ενέργεια θέλει έγκριση. [Πού τρέχει το μοντέλο και τι δεδομένα του στέλνουμε.] |
| Πώς ενσωματώνεται σε υπάρχοντα συστήματα; | Κάθε σύστημα είναι ένα εργαλείο λίγων γραμμών. Όπου δεν υπάρχει API, ο agent χειρίζεται τον browser όπως ένας υπάλληλος. |
| Τι το κάνει δύσκολο να αντιγραφεί; | [Γνώση του κλάδου / τα δεδομένα / οι έλεγχοι που χτίσαμε]. Το μοντέλο αλλάζει με μία ρύθμιση· η αξία είναι στα εργαλεία και στους ελέγχους. |
| Ποιο είναι το επόμενο βήμα; | [Ένας συγκεκριμένος πρώτος χρήστης ή πιλότος, με ημερομηνία]. |
| Χρησιμοποιήσατε εργαλεία χορηγών; | [Ποιο, σε ποιο σημείο της ροής, και τι θα χάναμε χωρίς αυτό]. |
| Τι δεν δουλεύει ακόμη; | [Ένα ειλικρινές όριο] και πώς θα το λύναμε. Η ειλικρίνεια εδώ κερδίζει πόντους. |
